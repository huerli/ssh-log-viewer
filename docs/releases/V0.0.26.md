# SSH Log Viewer V0.0.26

发布日期：2026-11-07

## 连接选择更清晰

- SSH 已保存连接按“直连”和“跳板连接”分组展示，跳板连接保留所经服务器说明。
- Telnet 启动默认显示“新增连接”，不再自动选中首个已保存的直连配置。
- 新增 Telnet 连接从空白主机开始；未填写主机时点击“连接”会打开配置窗口。

## 收藏路径整合到路径输入框

- 点击远程路径输入框，直接在框下方展开收藏路径和最近访问列表，移除独立收藏栏。
- 点击收藏或历史路径即可回填，已连接时自动进入该目录；未连接时保留所选路径。
- 保留手动输入和星标收藏操作，支持 Esc 或点击外部收起列表。

## 文件上传与启动修复

- SSH 支持递归上传文件夹，保留目录结构和空目录，不跟随符号链接。
- SSH 终端与日志查看共用远程文件浏览区，便于在终端操作时浏览和上传文件。
- 修复 macOS 自带 Bash 在严格模式下展开空数组导致启动失败的问题。
- 修复反向 SSH 参数解析脚本在 macOS 系统 AWK 下的语法兼容问题。

## 升级与安装

通过“设置 → 软件更新”升级，或下载对应系统安装包。源码运行请更新代码后关闭旧窗口，重新执行：

```bash
./start.sh
```

首次运行需先安装依赖：`pnpm install`（或 `npm install`）。

- Linux x64：`ssh-log-viewer-0.0.26-linux.deb`
- Windows x64：`ssh-log-viewer-0.0.26-windows.exe`
- macOS ARM64：`ssh-log-viewer-0.0.26-macos.dmg`
- macOS Intel x64：`ssh-log-viewer-0.0.26-macos-x64.dmg`

安装包提供 SHA-256 校验文件及对应架构的更新元数据。已保存连接、收藏路径和历史路径继续保留。
