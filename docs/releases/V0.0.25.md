# SSH Log Viewer V0.0.25

发布日期：2026-11-02

## 日志统一在“日志查看”标签打开

- 修复查看日志时仍停留在 SSH 或 Telnet 标签的问题。
- 从左侧文件列表、右侧已下载文件、下载或解压任务以及搜索结果打开日志，统一切换到“日志查看”标签。
- SSH、Telnet 标签保留终端输出，切回后可继续操作。
- 远程日志复用来源 SSH 连接读取，支持实时跟随，无需额外建立连接。来源连接断开后，已完成缓存的日志仍可查看。

## 升级与安装

通过“设置 → 软件更新”升级，或下载对应系统安装包。源码运行请更新代码后关闭旧窗口，重新执行：

```bash
./start.sh
```

- Linux x64：`ssh-log-viewer-0.0.25-linux.deb`
- Windows x64：`ssh-log-viewer-0.0.25-windows.exe`
- macOS ARM64：`ssh-log-viewer-0.0.25-macos.dmg`
- macOS Intel x64：`ssh-log-viewer-0.0.25-macos-x64.dmg`

安装包提供 SHA-256 校验文件及对应架构的更新元数据。新版更新说明排版在安装本版本后生效。
