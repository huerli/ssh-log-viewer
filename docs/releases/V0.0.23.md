# SSH Log Viewer V0.0.23

发布日期：2026-11-01

## 可靠传输 DB 查看器

- 右上角新增“可靠传输 DB”入口，可选择或拖入本地 `alarm`、`event`、`wholercd`、`oob_action` 文件，最大支持 16 MiB。
- 常规文件打开流程自动识别可靠传输文件，包括支持的压缩后缀；缓存、解压后在中央区域直接展示。
- 按业务自动选择 128 B 或 256 B 槽位，支持手动切换槽位大小及大小端字节序。
- 分别展示本地存储序号、传输序号、设备/单板序列号、唯一标识、数据长度和确认状态。
- 支持待确认、成功回复、错误回复、异常记录筛选，以及业务类型、序号和唯一标识搜索。
- 记录按时间倒序排列，转换为本地时间并保留原始值；全部匹配记录在可滚动表格中展示。
- 点击记录查看业务字段、告警和全程记录类型说明、业务体及完整原始槽位；保留未解析尾部数据。
- 全 FF 空槽仅计数；标注截短槽位、非法长度、未知类型和异常状态，避免越界解析。

本地 `state` 表示确认结果；非零错误回复也会结束重发。文件中待确认记录数不等于设备内存待发列表数量。

## 升级与安装

通过“设置 → 软件更新”升级，或下载对应系统安装包。源码运行请更新代码后执行 `./start.sh`，关闭旧窗口并重启。

- Linux x64：`ssh-log-viewer-0.0.23-linux.deb`
- Windows x64：`ssh-log-viewer-0.0.23-windows.exe`
- macOS ARM64：`ssh-log-viewer-0.0.23-macos.dmg`
- macOS Intel x64：`ssh-log-viewer-0.0.23-macos-x64.dmg`

每个安装包提供 SHA-256 校验文件及对应架构的更新元数据。
