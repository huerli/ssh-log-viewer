# SSH Log Viewer V0.0.15

发布日期：2026-10-26

## 日志查看

- 支持从文件管理器向中央日志查看区域拖入单个本地文件或文件夹。文件直接打开，文件夹加载到文件列表，可继续选择日志和搜索。
- 拖入时显示释放提示，一次拖入多个项目时会提示逐个打开。
- 打开日志默认预览开头并从首行查看，修复后台索引完成时自动跳到末行的问题。
- 保留“首行”“末尾”、搜索结果定位和实时跟随功能。

## 配置导出

- 登录配置与 SSH / Telnet 命令分组统一使用 Electron 异步保存接口，替换浏览器下载路径，改善导出时的卡顿问题。
- 保存期间禁用重复导出，文件写入完成后才显示成功；取消或失败后可再次导出。
- 登录配置继续排除密码、私钥口令和 Web 令牌，导入后需重新填写。

## 外观与字体

- 新增“陶土橙”浅色主题，支持保存并在重启后恢复。
- 改善 Unicode 罗马数字（如 Ⅲ、Ⅷ）在日志和终端字体中的辨识度。

## 升级与安装

在“设置 → 软件更新”检查并升级，也可下载对应系统安装包手动安装。源码运行请更新代码后执行 `./start.sh`，关闭旧窗口并重新启动。

- Linux x64：`ssh-log-viewer-0.0.15-linux.deb`
- Windows x64：`ssh-log-viewer-0.0.15-windows.exe`
- macOS Apple Silicon（ARM64）：`ssh-log-viewer-0.0.15-macos.dmg`
- macOS Intel（x86_64）：`ssh-log-viewer-0.0.15-macos-x64.dmg`

每个安装包同时提供 SHA-256 校验文件和独立架构更新元数据。
