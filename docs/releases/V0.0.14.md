# SSH Log Viewer V0.0.14

发布日期：2026-10-25

## macOS 一键升级

- 点击“退出并安装”后，macOS 会在后台挂载已校验的 DMG，替换当前 `.app` 并重新启动应用。
- 更新过程会先等待当前应用退出，再完成替换和磁盘映像卸载。
- 如果应用目录没有写入权限或系统阻止替换，可使用“显示安装包”手动安装。

Windows 和 Linux 的更新流程保持不变。

## 升级与安装

可在“设置 → 软件更新”检查并升级，也可下载对应系统安装包手动安装。源码运行请更新代码并重启应用。

- Linux x64：`ssh-log-viewer-0.0.14-linux.deb`
- Windows x64：`ssh-log-viewer-0.0.14-windows.exe`
- macOS Apple Silicon（ARM64）：`ssh-log-viewer-0.0.14-macos.dmg`
- macOS Intel（x86_64）：`ssh-log-viewer-0.0.14-macos-x64.dmg`

每个安装包同时提供 SHA-256 校验文件和独立架构更新元数据。
