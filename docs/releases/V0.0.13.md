# SSH Log Viewer V0.0.13

发布日期：2026-10-25

## 登录配置迁移

- 在“设置 → 登录配置迁移”中导出或追加导入 SSH 连接、SSH 跳板机、Telnet 直连和 Web Telnet 节点。
- 导入会追加配置，名称冲突时自动生成新名称，不覆盖现有配置。
- 导出 JSON 只包含主机、端口、用户名、认证方式、私钥路径等可迁移设置，不包含密码、私钥口令、Web 令牌、凭据标识或已加密密码内容。
- 导入后请在 SSH 或 Telnet 设置中重新填写密码并保存；已有配置和当前连接不会被覆盖。

## 按钮分组

- “调整分组”窗口新增“一键导出全部”，可一次备份当前协议的所有按钮分组。
- 导出内容保留分组顺序、命令顺序、命令文本和自定义颜色。

## 升级与安装

可在“设置 → 软件更新”检查并升级，也可下载对应系统安装包手动安装。源码运行请更新代码并重启应用。

- Linux x64：`ssh-log-viewer-0.0.13-linux.deb`
- Windows x64：`ssh-log-viewer-0.0.13-windows.exe`
- macOS Apple Silicon（ARM64）：`ssh-log-viewer-0.0.13-macos.dmg`
- macOS Intel（x86_64）：`ssh-log-viewer-0.0.13-macos-x64.dmg`

每个安装包同时提供 SHA-256 校验文件和独立架构更新元数据。
