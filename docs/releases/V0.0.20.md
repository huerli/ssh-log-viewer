# SSH Log Viewer V0.0.20

发布日期：2026-10-26

## 界面与连接状态

- SSH 与 Telnet 标题及连接状态标签采用一致的字号、字重、行高和间距。
- SSH 保留原有宽连接按钮，右侧依次为断开、设置；状态显示在左侧标题旁。
- 修正 SSH 在后台连接成功时因页面未激活而被误判为未连接的问题。
- 删除顶部连接信息标签、底部状态栏，以及日志模式下终端容器残留的黑色占位。
- 保留搜索结果、标注面板和 SSH/Telnet 页面切换时的连接。
- 删除 SSH 输出区的清屏按钮及其多余占位；终端连接失败时仍可重试。

## 文件传输设置

- 将“强制覆盖”从左侧上传栏移至右上角“设置 → 文件传输”。
- 使用与 SSH/Telnet 启用选项一致的滑动开关，默认关闭。
- 开启后上传覆盖远程同名普通文件；关闭时保留同名文件并跳过。

## 发布流程

- SSH 上传前清理私钥中的 CR 换行并验证私钥格式，配置错误时给出明确提示。
- 继续通过自有 HTTPS 服务器提供更新检查和安装包下载，保留大小、架构与 SHA-256 校验。

## 升级与安装

通过“设置 → 软件更新”升级，或下载对应系统安装包。源码运行请更新代码后执行 `./start.sh`，关闭旧窗口并重启。

- Linux x64：`ssh-log-viewer-0.0.20-linux.deb`
- Windows x64：`ssh-log-viewer-0.0.20-windows.exe`
- macOS ARM64：`ssh-log-viewer-0.0.20-macos.dmg`
- macOS Intel x64：`ssh-log-viewer-0.0.20-macos-x64.dmg`

每个安装包提供 SHA-256 校验文件及对应架构的更新元数据。
