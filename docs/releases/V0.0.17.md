# SSH Log Viewer V0.0.17

发布日期：2026-10-26

## SSH / SFTP 上传

- 连接 SSH 后，在左侧“远程文件”目录点击“上传”，选择一个或多个本地文件上传到当前远程目录。
- 支持将本地文件直接拖入左侧远程文件列表，拖动时显示当前目标目录。
- 上传任务显示当前文件、总进度、成功/失败数量，并支持取消；完成后自动刷新远程目录。
- 支持中文文件名、空文件和二进制文件。
- 默认不覆盖远程同名文件，并提示“远程同名文件已存在，已跳过”。
- 勾选“强制覆盖”后，可覆盖远程同名普通文件；远程目录和符号链接不会被覆盖。
- 上传失败或取消时会清理本次创建的未完成文件。

## 升级与安装

在“设置 → 软件更新”检查并升级，也可下载对应系统安装包手动安装。源码运行请更新代码后执行 `./start.sh`，关闭旧窗口并重新启动。

- Linux x64：`ssh-log-viewer-0.0.17-linux.deb`
- Windows x64：`ssh-log-viewer-0.0.17-windows.exe`
- macOS Apple Silicon（ARM64）：`ssh-log-viewer-0.0.17-macos.dmg`
- macOS Intel（x86_64）：`ssh-log-viewer-0.0.17-macos-x64.dmg`

每个安装包同时提供 SHA-256 校验文件和独立架构更新元数据。
