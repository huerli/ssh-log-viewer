# SSH Log Viewer V0.0.21

发布日期：2026-10-29

## 多会话标签页

- SSH、Telnet 连接采用独立会话，点击连接配置的“连接”按钮自动新建并激活标签。
- 切换标签时保持后台连接、终端输出、文件列表和搜索状态；关闭标签只断开对应连接。
- 固定保留一个不可关闭的“日志查看”标签，本地日志复用该页面。
- 移除顶部“日志查看 / SSH 输出 / Telnet 输出”按钮，统一通过标签切换。
- 应用退出时清理全部会话；重启后不自动恢复连接。

## 界面与设置

- 搜索范围、高亮输入、字体设置和日志导航操作合并为一行；中间区域宽度不足时隐藏范围说明，避免挤成竖排。
- 标签采用平面选中状态，取消悬停浮起、缩放与阴影。
- 新标签继承当前主题，终端按当前配色初始化，修复连接时短暂闪黑。
- 左侧连接栏、右侧已下载文件栏支持独立收起与展开，状态自动保存并在标签间同步；收起不影响连接。
- 上传“强制覆盖”开关自动保存，重启后恢复上次状态；首次使用默认关闭。

## 远程目录历史与收藏

- 成功访问的远程目录自动保存，按最近使用排序、去重，保留最近 30 条。
- 路径输入框支持历史下拉补全；访问失败的路径不加入历史，重启后历史保留。
- 路径右侧 ☆ 用于收藏，★ 用于取消收藏；从“常用位置”下拉选择跳转。
- 未连接时可先选择收藏路径填入输入框；收藏自动保存并在重启后保留。

## Debug 命令分组

- 新增分组时，可勾选同时生成 detail、trace、log 三个日志等级按钮；名称包含 debug 时自动勾选。
- 模块名默认 hmi，可修改，命令会随模块名更新，也可分别编辑。
- 默认命令为 `debug hmi detail on`、`debug hmi trace on`、`debug hmi log on`。
- 命令仍支持变量输入和现有按钮编辑、颜色及配置保存机制。

## 升级与安装

通过“设置 → 软件更新”升级，或下载对应系统安装包。源码运行请更新代码后执行 `./start.sh`，关闭旧窗口并重启。

- Linux x64：`ssh-log-viewer-0.0.21-linux.deb`
- Windows x64：`ssh-log-viewer-0.0.21-windows.exe`
- macOS ARM64：`ssh-log-viewer-0.0.21-macos.dmg`
- macOS Intel x64：`ssh-log-viewer-0.0.21-macos-x64.dmg`

每个安装包提供 SHA-256 校验文件及对应架构的更新元数据。
