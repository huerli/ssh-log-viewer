# SSH Log Viewer V0.0.12

发布日期：2026-10-25

## SSH 反向隧道清理

- 主动断开 SSH 或退出应用时，支持清理当前转发端口对应的持久 `reverse-ssh-worker`、其 SSH 子进程，以及手动启动的 `ssh -fCNR 转发端口:localhost:22 root@跳板地址 -p 10022` 专用隧道。
- 先停止持久 worker 的重连循环，再结束匹配的 SSH 客户端；即使清理过程中当前连接立即断开，独立清理流程也能继续处理其余匹配进程。
- 结合实际 TCP 连接归属识别当前隧道，兼容跳板域名、IP 别名与端口映射。保留其他端口、目的地址及已确认不同账号的连接，不处理普通 SSH 命令或复用连接。
- 修复 BusyBox 环境下读取 TCP 归属失败的问题，支持 BusyBox ash、awk、readlink 与 IPv4/IPv6。
- 修复实际停止后因等待通道关闭而误报超时的问题；清理阶段会显示进度，无法最终确认设备进程时明确提示待核验状态，并继续检查跳板端口。

## Telnet、按钮与日志

- 直连 Telnet 支持新增、保存、切换、修改和删除多个连接配置，重启后保留。
- 取消直连成功后自动发送 `send dev-get-info`，避免不支持该命令的设备出现错误提示。
- 修复在 Telnet 输入框按回车或点击发送时不显示本地回显的问题；回显开关对两种发送方式一致生效。
- “调整分组”中可单独导出对应分组的 JSON 按钮配置，保留名称、命令、颜色及顺序，支持重新导入。
- 新建 SSH/Telnet 输出日志及另存文件保留连接名称、车号、设备号和地址等已知来源信息，支持中文名称，便于区分机车和设备。历史日志维持原有目录。
- 按钮新增悬停上浮、阴影渐变和按下反馈，保留命令按钮自定义颜色，并适配系统减少动态效果设置。

## 升级与安装

可在“设置 → 软件更新”检查并升级，也可下载对应系统安装包手动安装。源码运行请更新代码并重启应用。

- Linux x64：`ssh-log-viewer-0.0.12-linux.deb`
- Windows x64：`ssh-log-viewer-0.0.12-windows.exe`
- macOS Apple Silicon（ARM64）：`ssh-log-viewer-0.0.12-macos.dmg`
- macOS Intel（x86_64）：`ssh-log-viewer-0.0.12-macos-x64.dmg`

每个安装包同时提供 SHA-256 校验文件和独立架构更新元数据。

主动断开会停止对应反向隧道，下次连接前需从设备重新建立。若设备上的其他守护服务会重新拉起隧道，还需停止设备端对应服务。手动隧道自动清理仅识别使用 `-N`、只含一个转发到本机 22 端口的 `-R` 的专用 SSH 客户端。
