# SSH Log Viewer V0.0.11

发布日期：2026-10-25

- Web Telnet 支持在同一输入框同时按设备号和车号搜索，无需切换查询方式。
- 车号查询会根据车辆绑定 ID 获取对应终端设备；设备号查询也会补齐设备绑定的车号。
- 搜索结果统一按“车号 · 设备号”显示，并合并重复设备，保留在线状态；无法获取车号时显示“未知车号”。
- 同一车辆的设备复用车号查询结果，其中一种查询失败时仍保留另一种查询获得的可用设备。
- 输入关键词后请先从搜索结果中选择设备，再点击“连接”，避免将车号作为设备号连接。

可在“设置 → 软件更新”中检查并升级，也可以下载对应系统的安装包手动安装。源码运行请更新代码并重启应用。

补充发布：Intel Mac（x86_64）请下载 `ssh-log-viewer-0.0.11-macos-x64.dmg`；Apple Silicon（ARM64）请下载 `ssh-log-viewer-0.0.11-macos.dmg`。Intel 包使用 V0.0.11 原标签源码构建，并附带校验文件和独立架构更新元数据。
