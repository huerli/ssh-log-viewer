## SSH 连接与页面切换

- SSH 连接成功后自动进入 SSH 输出页面。
- 修复切换到 Telnet 时前端误清空 SSH 连接状态的问题。
- 返回 SSH 页面复用原有终端会话，避免重复打开终端；手动断开仍正常生效。

## 升级与安装

在“设置 → 软件更新”中升级，或下载对应安装包手动安装。源码运行请更新后执行 `./start.sh`，关闭旧窗口并重启。

- Linux x64：`ssh-log-viewer-0.0.19-linux.deb`
- Windows x64：`ssh-log-viewer-0.0.19-windows.exe`
- macOS ARM64：`ssh-log-viewer-0.0.19-macos.dmg`
- macOS Intel x64：`ssh-log-viewer-0.0.19-macos-x64.dmg`

每个安装包附带 SHA-256 校验文件及对应架构的更新元数据。
