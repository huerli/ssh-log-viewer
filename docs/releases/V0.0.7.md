# SSH Log Viewer V0.0.7

发布日期：2026-10-24

- 新增 SSH、Telnet 独立功能开关，控制输出入口、终端及对应配置入口；开关状态自动保存。SSH 默认关闭，Telnet 默认开启。
- 命令栏空白处右键菜单新增“导入配置…”入口，支持直接导入命令分组 JSON，追加配置而不覆盖已有分组。
- 优化设置面板、功能开关与子页面弹窗布局和间距。
- Telnet 的设置、连接、断开、清屏按钮与“本地回显”保持同一行，按钮自动铺满侧栏宽度。
- 恢复 SSH 连接按钮铺满布局，设置按钮靠右。
- 仅启用 Telnet 时移除顶部分隔线和留白；同时启用 SSH 与 Telnet 时加粗、加深分隔线。

提供 Linux DEB、Windows 安装程序与 macOS DMG，附带 SHA-256 校验文件和自动更新元数据。
