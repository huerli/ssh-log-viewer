# SSH Log Viewer V0.0.24

发布日期：2026-11-02

## SQLite 数据库查看

- 新增只读 SQLite 查看器，按文件头自动识别数据库，支持 `.db`、`.map` 及 gzip 压缩文件。
- 支持选择表或视图、查看字段及建表 SQL，每页展示 100 条记录。
- 支持指定字段或全部字段搜索，提供包含和等于两种方式；搜索覆盖整个表。
- 大整数完整显示，长文本及 BLOB 展示摘要，BLOB 支持十六进制搜索。
- `fileid` 展示文件类型及枚举说明，MD5 使用等宽完整显示。
- 已使用 `prevention_params.db` 和 `1145584.map` 验证表读取及界面打开流程。

## 持续写入日志下载

- 普通日志按下载开始时的长度生成远程压缩快照，后续追加不再导致下载失败。
- 保留传输完整性、截断、同长度改写及文件开头变化检查；压缩归档仍要求下载期间保持不变。
- 远端需提供 `head`、`wc` 和 `gzip`，`/tmp` 需容纳原始快照和压缩文件。快照暂存文件在处理结束时清理。

## 已下载文件右键菜单

- 文件和文件夹均可右键选择“在资源管理器中打开”或“在左侧打开”。
- 对文件执行上述操作时打开其所在文件夹。
- 保留单击文件直接查看、单击文件夹展开或折叠的操作。

## 升级与安装

通过“设置 → 软件更新”升级，或下载对应系统安装包。源码运行请更新代码后执行 `./start.sh`，关闭旧窗口并重启。

- Linux x64：`ssh-log-viewer-0.0.24-linux.deb`
- Windows x64：`ssh-log-viewer-0.0.24-windows.exe`
- macOS ARM64：`ssh-log-viewer-0.0.24-macos.dmg`
- macOS Intel x64：`ssh-log-viewer-0.0.24-macos-x64.dmg`

每个安装包提供 SHA-256 校验文件及对应架构的更新元数据。
