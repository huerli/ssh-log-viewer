# SSH Log Viewer V0.0.18

发布日期：2026-10-26

## 日志查看与终端切换

- 日志查看窗口隐藏终端按钮栏和命令发送栏，日志内容获得完整可用空间。
- SSH 连接后切换到 Telnet 输出页面时保持 SSH 终端连接。
- 返回 SSH 输出页面后可继续使用原有 SSH 终端会话。
- 显式断开 SSH 或 Telnet 时仍会正常关闭对应连接。

## 升级与安装

在“设置 → 软件更新”检查并升级，也可下载对应系统安装包手动安装。源码运行请更新代码后执行 `./start.sh`，关闭旧窗口并重新启动。

- Linux x64：`ssh-log-viewer-0.0.18-linux.deb`
- Windows x64：`ssh-log-viewer-0.0.18-windows.exe`
- macOS Apple Silicon（ARM64）：`ssh-log-viewer-0.0.18-macos.dmg`
- macOS Intel（x86_64）：`ssh-log-viewer-0.0.18-macos-x64.dmg`

每个安装包同时提供 SHA-256 校验文件和独立架构更新元数据。
