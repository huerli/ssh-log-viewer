# SSH Log Viewer V0.0.22

发布日期：2026-10-29

## 标签栏与会话复用

- 标签栏从 52px 缩小至 34px，减少顶部占用。
- Telnet 按 IP、端口匹配已有标签：已连接时直接切换，已断开时在原标签重连。
- 相同 IP 的不同端口仍使用独立标签；Web Telnet 按服务地址和设备号区分。
- SSH 在当前标签使用相同连接配置重连时复用原标签。

## SSH / Telnet 回车重连

- 连接断开后，在终端窗口或底部空命令输入框按 Enter 即可重连。
- 重连使用该会话原有连接配置，保留终端输出，不额外创建标签。
- Telnet 更换左侧配置后，原会话的回车重连仍使用原目标。
- SSH 整个连接断开时重新建立连接，仅命令终端通道断开时单独恢复终端。
- SSH 断开进行中收到回车重连请求时，等待断开完成后再连接。
- 防止连续回车触发并发重连。

## 界面与本地文件打开

- 移除窗口顶部 File、Edit、View、Window 原生菜单栏。
- 移除顶部及空白页的“打开本地文件/文件夹”按钮和本地选择弹窗。
- 切换到固定“日志查看”标签，将文件或文件夹从文件管理器拖入中央区域即可打开。
- 文件夹拖入后加载左侧本地列表，可继续浏览、查看及搜索；即使未启用 SSH，也可使用本地文件列表。
- 同步更新使用说明和桌面测试，改用真实文件拖入事件验证。

## 升级与安装

通过“设置 → 软件更新”升级，或下载对应系统安装包。源码运行请更新代码后执行 `./start.sh`，关闭旧窗口并重启。

- Linux x64：`ssh-log-viewer-0.0.22-linux.deb`
- Windows x64：`ssh-log-viewer-0.0.22-windows.exe`
- macOS ARM64：`ssh-log-viewer-0.0.22-macos.dmg`
- macOS Intel x64：`ssh-log-viewer-0.0.22-macos-x64.dmg`

每个安装包提供 SHA-256 校验文件及对应架构的更新元数据。
