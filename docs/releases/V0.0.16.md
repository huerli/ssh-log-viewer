# SSH Log Viewer V0.0.16

发布日期：2026-10-26

## 日志滚动修复

- 修复日志查看停留在末行、向上滚动后又被拉回末尾的问题。
- 将用户主动跳转与布局调整分开处理；查看区高度变化时保留当前阅读位置，不再重复执行上一次“末尾”或行号跳转。
- 避免长日志横向滚动条显隐、窗口尺寸变化等布局更新干扰阅读，并关闭日志查看区的浏览器滚动锚定。
- 保留从首行打开、首行/末尾按钮、搜索结果定位和实时跟随功能。
- 新增“跳到末尾 → 向上滚动 → 调整窗口 → 继续上滑”桌面回归验证。

## 升级与安装

在“设置 → 软件更新”检查并升级，也可下载对应系统安装包手动安装。V0.0.15 用户建议升级以获得本次滚动修复。源码运行请更新代码后执行 `./start.sh`，关闭旧窗口并重新启动。

- Linux x64：`ssh-log-viewer-0.0.16-linux.deb`
- Windows x64：`ssh-log-viewer-0.0.16-windows.exe`
- macOS Apple Silicon（ARM64）：`ssh-log-viewer-0.0.16-macos.dmg`
- macOS Intel（x86_64）：`ssh-log-viewer-0.0.16-macos-x64.dmg`

每个安装包同时提供 SHA-256 校验文件和独立架构更新元数据。
