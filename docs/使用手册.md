# SSH Log Viewer 使用手册

## 快速开始

安装版：安装对应系统的安装包后，从应用菜单启动 **SSH Log Viewer**。Linux 使用 `.deb`，Windows 使用安装程序，macOS 使用 `.dmg`。

Linux 安装下载的 deb 包：

```bash
sudo apt install ./ssh-log-viewer-*.deb
```

源码版：在仓库目录安装依赖后启动，需要 Node.js 24 和项目声明的 pnpm 版本。

```bash
pnpm install --frozen-lockfile
./start.sh
```

`start.sh` 每次启动会重新构建界面，优先使用系统 Node.js，在当前机器上也支持回退到已有的 Codex Node 运行时。依赖尚未安装时会提示先安装；安装依赖需要联网下载 Electron。关闭应用窗口即可停止。

**安装版与源码版更新方式不同**：修改源码后需要重启源码版；已安装的程序需要安装新构建的安装包。本文以当前仓库功能为准，旧安装包可能没有最新功能。

## 检查与安装新版本

1. 启动后默认自动检查新版本，此后每 6 小时检查一次。检查结果显示在设置界面的软件更新区域；点击“设置 → 软件更新 → 检查更新…”查看详情。
2. 更新窗口显示当前版本、最新正式版本、发布时间及更新说明。可取消“启动时及每 6 小时自动检查”，设置会保存。
3. 点击“下载更新”，等待下载及文件校验完成。下载可取消，失败可重试；不匹配的系统/架构、损坏文件或不完整下载不会用于安装。
4. 点击“退出并安装”打开系统安装程序并退出应用。此操作会断开 SSH/Telnet，跳板机 localhost 端口按断开规则释放。Windows 按安装向导操作；Linux 使用系统软件安装器；macOS 打开磁盘映像后将新版应用放入“应用程序”。完成后重新启动应用。
5. 安装器无法打开时可重试，或点击“显示安装包”手动安装。旧版 Release 缺少自动更新元数据时，点击“查看发布说明”从发布页面手动下载。

自动检查不会自动下载或安装。更新源为项目 GitHub Releases，仅检测正式版本，不降级。需能够访问 GitHub；网络错误会明确显示，可稍后重试。源码版可下载和安装发行版，但不会修改源码工作区，安装后需从应用菜单启动新版本。

## 界面区域

| 区域 | 用途 |
| --- | --- |
| 左侧 SSH 连接管理 | 管理 SSH 服务器、直连和跳板连接，浏览远程文件 |
| 左侧命令连接 | 随 SSH / Telnet 模式显示终端控制，Telnet 支持直连与 Web 节点 |
| 中间日志查看 | 阅读日志、全文搜索、跳转、高亮与标注 |
| 中间 SSH / Telnet 输出 | 接收终端输出、直接输入命令，同时只显示一种命令面板 |
| 下方命令按钮 | 按分组发送固定命令或填写变量后发送 |
| 右侧已下载文件 | 浏览已下载、已解压文件和 SSH / Telnet 会话日志 |
| 右上角设置 | 修改主题、快捷键、存储目录及 SSH / Telnet 配置 |

SSH/SFTP 文件连接可持续保留。离开 Telnet、切换到 SSH 输出或日志查看时，Telnet 连接保持，后台继续接收输出和保存日志，返回即可继续发送命令。只有点击 Telnet“断开”、主动重连或退出应用时才关闭连接；远端也可能自行断开。切换到 Telnet 时仍关闭 SSH 命令通道，返回 SSH 时自动复用上方连接打开终端。点击“日志查看”只切换显示，不断开当前终端。Web 登录成功不代表设备终端已连接。

## SSH 直接连接

1. 在左上角选择已有连接，或选择“新建连接…”。
2. 点击旁边的“设置”，选择“直接连接”。
3. 填写连接名称、主机、SSH 端口、用户名与认证方式。
4. 密码认证填写密码；私钥认证选择私钥；SSH Agent 使用本机代理。
5. 需要跨启动保留密码时勾选“保存密码”，然后保存配置或连接。
6. 点击“连接”。首次连接核对服务器指纹，确认无误后信任。

连接后默认浏览 `/system/log`。可输入其他目录并前往，也可双击文件夹进入。

已保存连接列表中，`【直连】` 表示直接连接，`【跳板连接】` 表示通过跳板机连接，并显示跳板机名称。

## 通过跳板机连接

1. 打开 SSH 连接设置，选择“通过跳板机连接”。
2. 在“通过哪台服务器连接”中选择本地已保存的服务器，自动复用地址、账号及认证信息；其他服务器可使用“手动配置其他跳板机…”。
3. 在下方填写**目标服务器**的信息，与跳板机信息区分开。
4. 点击连接，或保存为一个独立的目标连接配置。

切换到跳板模式时，目标默认值为：

| 字段 | 默认值 |
| --- | --- |
| 主机 | `127.0.0.1` |
| 端口 | `2223` |
| 用户名 | `root` |
| 密码 | 空，需手动填写 |

这些是目标设备的默认值，可按实际环境修改。`127.0.0.1:2223` 指**跳板机视角**的地址，适用于跳板机已有反向隧道监听的情况。应用只使用已有隧道，不自动创建反向隧道。目标可直接从跳板机访问时，填写目标在客户网络中的实际地址。

### 断开并释放 localhost 端口

点击上方“断开”会同时清理两种反向隧道：持久的 `/usr/local/sbin/reverse-ssh-worker` 及其 SSH 子进程，以及手动运行的 `ssh -fCNR 转发端口:localhost:22 root@跳板地址 -p SSH端口`。先停止 worker 的重连循环，再结束匹配的 SSH 客户端；完整清理流程独立于被关闭的隧道运行，避免中途断线导致剩余进程未清理。

通过跳板机访问 `localhost`、`127.0.0.1` 或 `::1` 时，按反向端口和当前 SSH 会话的实际 TCP 归属识别隧道，清理同一目的地址与账号的匹配客户端，再释放跳板机对应监听。兼容跳板机域名、IP 别名与端口映射。直连 SSH 时只处理能唯一确认的一组转发端口与目的地址，多个不同目标会报告无法确认。手动隧道要求使用 `-N` 且仅有一个转发到本机 22 端口的 `-R`；包含远程命令、其他转发、代理或连接复用选项的 SSH 不纳入清理。

操作中显示“断开中…”及清理阶段，收到完成标记后立即确认，不再单纯等待通道关闭。若隧道自断导致设备进程无法最终核验，会明确显示待核验说明并检查跳板端口；失败也会关闭本工具连接并说明原因。退出应用时同样执行清理。若设备守护服务重新拉起隧道，需要停止设备端对应服务。

此操作会停止设备原先建立的反向隧道，下次连接前需要从设备重新建立。Linux 跳板机需允许执行命令，并允许当前账户查看和结束对应隧道的 SSH 会话进程；无法确认监听归属、权限不足或监听未退出时会报告失败。只处理指定 localhost 端口，目标端口与跳板机 SSH 登录端口相同则拒绝释放。

切换至 Telnet 只关闭 SSH 命令通道，离开 Telnet 则保持连接；这两种切换都不释放该监听。连接失败、取消连接和内部重连也不执行释放。

## 查看、下载和解压日志

- 双击日志文件或点击“查看”打开；单击文件选中后可下载、解压。
- 文件名匹配支持 `*`、`?`，例如 `signal.2026-10-23.*`。
- 匹配多个文件后可使用“全部下载”或“全部下载并解压”。批处理失败项会显示错误，已完成文件保留。
- `.gz` 单文件日志打开时自动解压供查看。
- `.zip`、`.tar`、`.tar.gz`、`.tgz` 归档需使用列表下方的“解压”按钮，再打开其中的日志。
- “打开本地文件/文件夹”用于浏览本地内容；本地文件列表也支持解压匹配文件。

下载和远程解压的目录层级为：

```text
默认下载或解压目录/
  目标IP或跳板机配置名/
    远端文件夹名称/
      YYYY-MM-DD_HH/
        文件或归档解压目录
```

跳板连接按跳板机配置名归档。旧版本已经存入 `127.0.0.1` 目录的文件不会自动搬迁。同名下载不会直接覆盖已有文件。

## 搜索、跳转与复制

1. 输入关键词，确认“搜索范围”，点击“搜索全文”。
2. 需要区分大小写时勾选 `Aa`；需要正则表达式时勾选“正则”。普通搜索支持 `*` 通配。
3. 在下方查看结果，点击结果或“上一个 / 下一个”定位。

| 搜索范围 | 适用场景 |
| --- | --- |
| 当前打开文件 | 只搜索正在阅读的日志 |
| 已下载/解压文件 | 搜索本次选定的本地文件集合 |
| 本地文件夹 | 搜索本地目录中匹配的文件 |
| 匹配文件 | 按远程列表的文件名匹配范围搜索，优先使用可用的本地副本 |

从“已下载文件”点击一份日志时，会同步将本地搜索范围切换到该文件。正文里有关键词却没有结果时，先检查范围是否包含当前文件。

跳转会显示目标行并闪烁提示，长行会横向定位到匹配的关键词。跳转时暂停实时跟随，避免立即回到末尾。当前正文单行最多显示 12000 字符，超过该范围的匹配不能直接横向展示。

- `Ctrl+F`：选中文字时按字面内容搜索；未选择时聚焦搜索框。
- 上一个、下一个搜索结果的快捷键可在“设置”中修改。
- 复制选中的正文不包含左侧行号，多行保留换行。
- 单击行号可高亮整行，并在“标注”中填写备注和颜色。
- 选中文字后右键可高亮相同内容，或仅显示包含该内容的行。
- “导出结果”可保存已搜索到的结果；最多展示前 10000 条匹配。

## SSH 命令与输出

1. 先使用左侧连接管理连接 SSH，支持直接连接和跳板机连接。
2. 点击顶部“SSH 输出”即可自动打开终端，直接复用上方连接管理的连接、断开和设置，无需再次连接。也可先进入 SSH 输出，再点击上方“连接”。目标服务器需允许交互式 shell。
3. 可直接在终端键入命令，支持方向键、Tab 与 Ctrl+C；也可使用底部“SSH 输入”框和“发送”按钮。
4. 默认按钮为“当前目录”（`pwd`）和“列出文件”（`ls -lah`）。右键按钮或按钮栏可配置分组、命令、颜色、变量；在“设置 → SSH”中导入或导出分组。SSH 和 Telnet 分别保存配置。
5. 输出支持 Ctrl+F、大小写与正则搜索，与 Telnet 共用主题和字体设置。服务器负责回显输入，界面不额外重复回显。
6. 默认自动保存到 `下载目录/ssh/YYYY-MM-DD/连接名称--用户名@主机_端口/`，每次打开终端生成独立文件；清屏不会清空日志。可在“设置 → SSH → 保存输出…”另存副本，在“日志设置…”选择可打印输出、所有输出或停止记录。覆盖仅清空当前会话日志。
7. 上方“断开”同时关闭 SSH 主连接和命令终端。切换至 Telnet 时只关闭 SSH 命令通道，文件浏览继续可用；返回 SSH 输出自动重开命令终端。终端打开失败或远端关闭 shell 后，可点击输出区“重试终端”。

## Telnet 连接与输出

### 直连设备

1. 点击顶部“Telnet 输出”，在 Telnet 下拉框选择直连，点击旁边的“设置”。
2. 点击“新增直连”，填写名称、设备 IP 与 Telnet 端口并保存。可保存多个直连配置，在左侧下拉框切换后点击连接；在设置中选择已有配置可修改或删除，配置重启后保留。
3. 连接成功后可在终端中输入命令，或使用下方命令按钮。

直连建立后不自动发送命令；需要获取设备信息时，可手动点击“设备信息”按钮。

### Web 远程设备

1. 打开 Telnet 连接设置，选择“Web 远程设备”。
2. 配置登录节点名称、HTTP(S) 服务地址及账号信息并保存。
3. 在“设备/车号”框输入关键词，系统同时按设备号和车号查询，并合并去重。车号先查询车辆，再根据车辆绑定 ID 查询对应终端设备。设备号命中后也会根据绑定车辆补齐车号。结果固定按“车号 · 设备号”显示，车号无法获取时标注“未知车号”；请先选择结果再连接。状态点绿色表示在线，灰色表示离线；状态仍受服务接口返回及网络情况影响。
4. 点击连接，等待 Telnet 状态显示“已连接”。

Web 连接中断后会自动重试，可点击“断开”停止。连接诊断保存在用户配置目录的 `logs/telnet-connection.log`，用于排查连接过程，不等同于设备输出日志。

### 终端操作

- 点击终端后输入命令，按 Enter 发送。
- “本地回显”控制本机是否显示输入内容，不控制设备自己的回显。
- “清屏”只清理当前终端显示，不删除已保存日志。
- 终端搜索框查找的是终端保留的输出；需搜索完整历史时，在“已下载文件”中打开会话日志并全文搜索。
- 终端有选中文本时 `Ctrl+C` 用于复制；没有选择时会向设备发送中断字符，设备是否处理取决于其协议支持。

## Telnet 自动日志

默认按可打印输出自动记录。每次发起连接创建一个独立 `.log` 文件，位于设置中的默认下载目录：

```text
Web Telnet：telnet/YYYY-MM-DD/车号--设备-设备号--节点名称--服务地址/连接时间-唯一标识.log
直连 Telnet：telnet/YYYY-MM-DD/直连名称--主机_端口/连接时间-唯一标识.log
```

名称保留中文；未填写名称时使用已知的设备号或连接地址，文件夹中的特殊字符会转换为安全字符。SSH 同时保留目标账号、端口和跳板地址。历史日志保持原有目录，缺少来源信息的旧日志不会自动补填车号。日期使用本机日期；同一设备重复连接会保留各次日志。“已下载文件”中可直接找到这些文件，手动点击刷新也可重新扫描。

进入“设置 → Telnet → 日志设置…”：

| 选项 | 效果 |
| --- | --- |
| 不记录 | 停止向会话日志写入后续输出 |
| 记录可打印输出 | 去掉终端控制序列后保存，适合阅读和搜索 |
| 记录所有输出 | 保留收到的输出，包括控制序列 |
| 追加日志文件 | 继续向当前会话日志追加 |
| 覆盖日志文件 | 点击应用时清空当前会话日志，历史会话文件保留 |

点击“应用”直接生效，不弹出文件选择框。尚未连接时可先设置日志类型，下次连接自动创建文件。日志类型在重启后保留。

## 命令按钮与分组

右键按钮栏空白处显示快捷菜单：选择“新增按钮…”打开简洁的新增窗口，选择“调整分组…”单独管理分组。完整配置和导入导出位于“设置 → 日志模式设置 → SSH / Telnet → 命令按钮 / 分组导入导出…”。右键已有按钮仍可编辑或删除。

- “调整分组”支持新增、重命名、删除分组，使用 ↑ ↓ 调整分组列表顺序；下拉列表切换当前分组。每个分组旁的“导出”可下载仅包含该分组的 JSON 按钮配置（含命令内容、颜色及顺序），可通过“导入配置…”重新导入。
- 为按钮填写简短名称及命令内容，保存后点击发送。
- 新建按钮会从协调的配色中随机选色，优先使用尚未使用的颜色；点击“换个颜色”重新选择，也可手动选择。文字颜色自动适配；“默认颜色”恢复主题样式。已保存按钮颜色不会自动改变。
- 编辑区位于列表外，命令内容可多行展示，长列表单独滚动。

### 可变命令按钮

使用双花括号表示每次发送前需要填写的变量。

地图 MD5 示例：

```text
system cmd find / -name "{{map文件名}}" -exec md5sum {} \;
```

反向 SSH 隧道端口示例：

```text
system cmd ssh -fCNR {{转发端口}}:localhost:22 root@服务器域名 -p 10022
```

点击可变按钮后，先填写参数，查看命令预览，再点击“发送命令”。取消不会发送。重复变量只需填写一次；不同变量分别填写。`find -exec` 中的 `{}` 保持不变，不是应用变量。

可变按钮显示 `{ } 参数` 标签、虚线边框和省略号，便于区分普通按钮。地图文件名会保存最近 20 条已确认发送的历史，自动去重、默认填入最近值；输入框提供历史下拉建议，右侧可清除历史。历史保存在本地，重启后保留。

## 命令配置导入与导出

在按钮配置窗口中选择“导出当前分组”或“导出全部分组”，获得 JSON 文件。“导入分组与命令…”可导入相同规格的文件。

导入为**追加分组**，不会覆盖或按同名自动合并已有分组。重复导入同一文件会产生重复分组；导入时重新生成内部 ID。

最小示例：

```json
{
  "format": "ssh-log-viewer-telnet-commands",
  "version": 1,
  "groups": [
    {
      "name": "地图",
      "commands": [
        {
          "name": "地图MD5",
          "text": "system cmd find / -name \"{{map文件名}}\" -exec md5sum {} \\;",
          "color": "#2563eb"
        }
      ]
    }
  ]
}
```

`color` 可省略；指定时使用 `#RRGGBB`。变量直接写在 `text` 中，无需额外字段。文件须为 UTF-8 JSON，最大 5MB；包含 1–200 个分组，每组最多 1000 个按钮，名称及命令内容不能为空。

已配置 `telnet-command-import` skill 的 Codex 环境可根据命令清单生成导入文件。相同操作仅参数不同的命令可聚合成变量按钮。生成文件后仍需在应用中导入，skill 不会自动执行设备命令。

## 设置与常见问题

右上角“设置”分为独立的“软件更新”和“日志模式设置”区域：软件更新管理版本检测与升级；日志模式设置包含并排的 SSH / Telnet 配置，以及外观、搜索快捷键和文件存储。目录和主题等操作会自动保存。

| 问题 | 检查方法 |
| --- | --- |
| 更新代码后界面没变化 | 关闭旧窗口，重新运行源码版；安装版需安装新包 |
| Web 登录成功但不能发送命令 | 检查设备编号及 Telnet 是否显示已连接 |
| 跳板机连接失败 | 检查跳板机账号、目标地址及隧道端口，确认跳板机允许 TCP 转发 |
| 搜索结果为 0，正文却有关键词 | 选择“当前打开文件”重试，核对大小写、正则与搜索范围 |
| 找不到 Telnet 日志 | 检查默认下载目录及日志类型是否为“不记录”，刷新“已下载文件” |
| 归档不能直接查看 | `.zip`、`.tar` 等先解压；单文件 `.gz` 可直接打开 |
| 大行关键词没有出现在跳转位置 | 确认是否超过正文单行 12000 字符的显示上限 |
| 导入配置失败 | 检查 JSON 语法、文件大小、必填字段及颜色格式 |
