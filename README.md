# SSH Log Viewer

## 快速开始

当前工作区已安装依赖并构建，Linux 下直接运行：

```bash
cd ssh-log-viewer
./start.sh
```

`start.sh` 优先使用系统 Node.js；当前机器未安装系统 Node 时，会使用 Codex 已有的 Node 运行时。

启动脚本每次启动会重新构建当前界面，避免继续使用旧的 `dist`。窗口标题及左上角显示版本号（当前为 `v0.0.11`）；更新代码后需要重启旧窗口，已运行的窗口不会自动更新。界面和后台版本不一致时会提示重启。

在“设置 → 软件更新”中检查并升级发行版；默认启动后自动检查，之后每 6 小时检查一次，可在“设置 → 软件更新”关闭。发现新版本后点击“下载更新”，校验完成再点击“退出并安装”，Linux 通过系统管理员授权调用 APT 安装，成功后退出；取消授权或安装失败时可重试或显示安装包手动安装。Windows 与 macOS 通过系统安装程序完成升级。源码运行时下载的是发行版安装包，不会覆盖当前工作区；安装后从应用菜单启动新版本。

Linux 下若 Electron 的 `chrome-sandbox` 没有配置 root 所有权及 SUID 权限，启动器与应用会跳过此助手，使用 Chromium 用户命名空间沙箱。当前机器已验证支持，不需要修改系统文件权限。参见 [Chromium Linux 沙箱说明](https://chromium.googlesource.com/chromium/src/+/HEAD/docs/linux/sandboxing.md)。

其他机器使用 Node.js 24 LTS：

```bash
pnpm install
pnpm build
pnpm start
```

关闭应用窗口即可停止运行。`start.sh` 不自动安装依赖；参数原样传递给 Electron，通常无需参数。

也可以使用 `npm install`、`npm run build` 和 `npm start`。安装过程需要网络下载 Electron。Linux 需要桌面环境与 GTK/NSS 等 Electron 系统依赖。

## 使用

完整操作说明见 [使用手册](docs/使用手册.md)。

右上角“颜色主题”可切换午夜蓝、晴空白、森林绿、暮光紫、石墨灰和暖砂金六套配色，其中晴空白与暖砂金为浅色主题。主题会自动保存，下次启动时恢复；切换主题不会重新读取日志或改变滚动位置，关键词高亮和手动标注颜色保留。

1. 输入主机、端口、用户名，选择密码、私钥或 SSH Agent 认证，点击连接后直接进入 `/system/log`。首次连接会要求核对服务器指纹；已保存的指纹改变时拒绝连接。若该目录不存在或无权限访问，界面会显示错误，可手动输入其他目录。
2. 勾选“保存密码”后，点击“保存配置”或连接成功会加密保存密码。下拉框显示当前配置；选择后自动回填信息和密码，下次启动恢复上次选择。不勾选后保存可删除该配置的已存密码。
3. 输入远程目录路径，或双击目录进入。文件名匹配框支持 `*`、`?`，例如 `signal.2026-10-12.*`；日期/关键词片段会自动匹配文件名中的内容，例如 `*10-13`、`10-13` 可匹配含该日期的 `.log` 和 `.log.gz`。带扩展名的完整文件名及以 `*`、`?` 结尾的模式保持完整匹配；输入模式后，全文搜索与 Ctrl+F 搜索会覆盖当前目录所有匹配文件（普通日志和 `.gz`），结果显示文件名和行号，点击后打开对应文件并跳到该行。匹配框下的“全部下载”将所有匹配文件保存到默认下载目录；“全部下载并解压”同时将压缩文件解压到默认解压目录，普通日志直接下载。逐个处理，显示文件进度，可取消；单个失败会继续处理其余文件并列出错误，已完成文件保留，取消后仍可从任务卡选择打开和搜索，重启后保留文件记录。批量下载或解压结束后自动打开首个日志，可在任务卡切换其他文件。清除模式恢复当前文件搜索；不递归子目录。批量搜索逐个缓存、搜索并清理，不向界面传输全文，可取消；单个文件失败会列出错误并保留其余结果。单击文件会将完整文件名填入上方匹配框，可复制或修改成通配符；自动填充保留当前列表及匹配范围，手动修改后应用新规则。双击普通文件查看，单击文件后可下载或解压。
4. 打开日志立即显示末尾预览，后台缓存全文并建立行索引。全文就绪后可搜索、跳转行号和标注。
5. 搜索支持字面关键词、大小写和正则；“搜索范围”可选择当前打开文件、本次解压文件（本地）、远程匹配文件。解压完成后自动选择本次解压文件，直接在本地搜索全部输出文件，不重新下载；打开普通本地日志时只搜索当前文件。远程匹配范围仍可显式选择。选中日志文本按 Ctrl+F 会直接按字面字符串搜索（无选中时聚焦搜索框）。结果在日志下方逐行显示，保留行号，点击跳转到上下文；支持横向滚动和收起面板。标注也移至下方标签页，下载/解压进度显示在左侧。正则搜索在独立工作线程执行，可以取消，最长执行 30 秒。
6. 选中日志中的文本后右键，可高亮所有相同字符串、仅显示包含该字符串的行、取消该字符串高亮。筛选扫描全文、保留原始行号；取消筛选恢复全部日志。筛选受搜索栏大小写开关控制，按字面字符串匹配，支持逗号和正则特殊字符。筛选时暂停实时跟随。
7. 高亮输入框支持逗号分隔的多个关键词；搜索中的字面关键词也会高亮。ERROR/FATAL 和 WARN/WARNING 有默认等级颜色。
8. 点击日志行号，输入备注和颜色，保存标注。标注保存在本地，关联连接、路径和打开时的文件版本。
9. 开启“实时跟随”后每 1.5 秒检查新增内容。关闭后暂停追加读取；重新开启会补读。检测到截断、文件头变化或本地文件替换时提示重新打开。
10. `.gz` 单文件日志可直接打开。`.zip`、`.tar`、`.tar.gz`、`.tgz` 使用解压按钮：远程归档先缓存，再在默认解压目录中创建独立子目录解压，完成后自动打开首个日志；多文件归档可在解压任务卡中选择其他文件。

日志区右侧的“已下载文件”面板按文件夹层级展示下载和解压目录中的已有文件，支持展开/收起文件夹、筛选和刷新，点击文件即可打开；下载完成或取消后自动更新。

右上角“目录设置”可选择并保存默认下载和解压目录，默认位于系统下载目录的 `SSH Log Viewer/downloads` 和 `SSH Log Viewer/extracted`。下载按“IP（跳板机连接使用跳板机配置名）/远端文件夹名称/下载时间（YYYY-MM-DD_HH）/原文件名”保存到默认下载目录，同名文件添加随机后缀，保留原文件。下载有进度和取消操作，先写临时文件，核对字节数与远程文件大小/修改时间后复制到目标路径。解压有进度和取消操作，拒绝目录穿越、链接和覆盖已有输出；单次解压上限 1GB、20000 个文件。

## 跳板机与已有反向隧道

连接方式分为“本地连接”（本机直接 SSH 到目标机器）和“通过跳板机连接”。选择跳板机模式后，可从下拉框选择独立保存的跳板机，或点“配置”填写名称、主机、端口及认证信息后“保存并使用”，支持多个跳板机；主界面填写目标机器的认证信息。目标连接记录引用所选跳板机，跳板机配置可独立更新和复用；旧版本附带的跳板机配置会自动迁移到列表。跳板机和目标机器分别支持密码、私钥或 SSH Agent，分别确认服务器指纹，密码独立加密保存。不勾选保存跳板机密码时仍可使用本次输入连接，重启后需重新输入；本次输入优先于保存的旧密码。密码认证同时支持单个普通密码提示的 keyboard-interactive；动态验证码、多提示交互暂不支持自动回答。连接中可取消，断开时清理两段 SSH 连接和转发通道。

- 跳板机可直接访问目标机器：主界面填写目标机器在跳板机网络中的地址和 SSH 端口。
- 目标机器已有反向隧道：主界面填写跳板机视角的 `127.0.0.1` 和反向隧道监听端口，例如 `2222`；用户名/密码仍填目标机器的账号。

在跳板机连接中，目标为 `localhost`、`127.0.0.1` 或 `::1` 时，点击上方“断开”或退出应用，会先通过跳板机释放该目标端口的反向 SSH 隧道监听，再关闭本工具的目标和跳板机连接。界面显示释放结果；释放失败时仍关闭本工具连接并显示原因。释放后，下一次连接前需从设备重新建立反向隧道。切换 SSH/Telnet 输出、连接失败、取消连接及工具内部重连不会释放监听端口。

工具通过 SSH 转发通道访问目标 SFTP，不需要跳板机提供 SFTP。文件浏览仅使用 SFTP；进入 SSH 输出模式时会在目标机器启动交互式 shell。跳板机必须允许 TCP 转发。工具连接已有反向隧道；目标机器需事先建立隧道，例如在目标机器执行：

```bash
ssh -N -o ExitOnForwardFailure=yes -R 127.0.0.1:2222:127.0.0.1:22 跳板机用户@跳板机地址
```

## SSH 命令面板

1. 使用左侧连接管理连接 SSH（支持密码、私钥、Agent 和跳板机），点击顶部“SSH 输出”即可自动打开终端，直接复用上方的连接、断开和设置。也可先进入 SSH 输出，再点击上方“连接”。
2. 在底部输入框发送命令，或直接在终端输入，支持方向键、Tab、Ctrl+C 等交互；使用服务器回显，避免命令显示两次。
3. 下方按钮栏与 Telnet 保持相同操作：右键配置按钮、分组、颜色及变量；右键按钮栏空白处可直接导入命令配置；“设置 → SSH”支持分组 JSON 导入导出。SSH 与 Telnet 各自保存按钮配置。
4. 输出默认自动保存到下载目录的 `ssh/YYYY-MM-DD/主机/`，每次打开终端新建日志。“设置 → SSH”可保存输出副本，或配置可打印输出、全部输出、不记录及覆盖当前会话日志。清屏不清空日志；日志显示在右侧“已下载文件”中。
5. 通过顶部“SSH 输出 / Telnet 输出”切换命令模式，离开 Telnet 时保持连接、继续接收输出和记录日志，返回即可继续发送命令；切换到 Telnet 时关闭 SSH 命令通道，返回 SSH 时自动复用上方连接打开终端。SSH/SFTP 文件浏览连接继续保留。关闭 SSH 主连接时，其命令终端同时关闭。

SSH、Telnet 使用相同的终端搜索、主题和字体设置。切换到“日志查看”仅切换显示区域，不关闭当前命令终端。

## Telnet 输出日志

每次发起 Telnet 连接时自动创建一个 `.log` 文件，输出持续追加，并显示在“已下载文件”中。Web Telnet 保存到默认下载目录的 `telnet/YYYY-MM-DD/设备号/`，直连 Telnet 保存到 `telnet/YYYY-MM-DD/IP/`。日期采用本机日期，文件名包含连接时间和唯一标识，重复连接不会覆盖旧日志。

## 性能设计

- 末尾预览最多读取 256KB，最多保留 2000 行。
- SFTP 有界并发预取：8 个 256KB 块，按原始顺序写入磁盘。
- 全文在本地临时磁盘缓存，不向界面传输整份日志；关闭文件后清理缓存，正常退出时清理本次临时目录。
- 后台工作线程扫描字节换行，每 512 行保存一个偏移检查点；中文多字节字符和 CRLF 不改变字节索引的准确性。
- 日志列表只渲染视口内的行，分页读取并预留少量上下文。滚动高度设上限，避免极多短行超出浏览器布局限制。
- 界面每行显示最多 12000 个字符；字面关键词搜索会扫描完整超长行，正则搜索对每行只处理前 1MB，并提示受影响的行数。搜索结果导出不受显示摘要限制，会从原始日志重新读取并导出完整单行。
- 最多展示 10000 条搜索结果，同时报告完整匹配行数。右键筛选单独保留最多 100 万个匹配行的行号与字节偏移（最多 16MB），按需读取匹配行，超出上限时提示；不会受搜索结果的 10000 条上限影响。

跳板机测试覆盖直接跳转、真实 SSH 反向隧道、跳板机私钥认证、独立指纹校验、认证失败/转发失败/取消清理，以及桌面端加密保存、重启重连和隧道断开。测试会生成 `docs/screenshot.png`、`docs/batch-transfer.png` 和 `docs/jump-host.png`。基准结果依赖本机硬件与网络，不能代表任意远程链路速度。

跳板机端口释放测试使用本地 SSH 服务和反向隧道，验证先执行释放再关闭连接、失败提示以及其他监听端口保留。

终端集成测试使用本地 SSH/PTY 与 Telnet 测试服务，验证输入、按钮、日志、导出以及切换后 Telnet 连接和后台日志保持，无需真实服务器。

## 打包

```bash
pnpm run pack
# 输出在 release/，Linux 为 release/linux-unpacked/ssh-log-viewer，安装包为 `.deb`
```

项目提供 Windows/macOS 打包配置，当前只在 Linux 验证。发布安装包前需要在对应系统验证；可使用 `pnpm exec electron-builder --linux AppImage` 等生成安装包。

发布流程为每个平台生成安装包、`.sha256` 和 `.update.json`，元数据包含版本、系统、实际打包架构、文件名、大小和 SHA-256；上传前及发布前均校验最终文件。手动收集安装包时使用 `node scripts/collect-release.cjs <linux|windows|macos> <版本> --arch <x64|arm64>`，并使用 `scripts/validate-updates.cjs` 验证。更新客户端仅使用公开正式 Release；检查 API 见 [GitHub Releases 文档](https://docs.github.com/en/rest/releases/releases#get-the-latest-release)。

## 当前范围

目前支持 UTF-8 日志、一个活动 SSH 连接和一个活动文件；全文搜索需要等待本地缓存完成。解压在本地执行。尚未实现多级跳板、多标签页、远程 grep、断点续传、GBK 编码选择和自动跟随新的轮转文件。

连接配置与标注使用用户数据目录中的 JSON 保存；连接密码加密保存于独立文件，优先使用系统密码库（[Electron safeStorage](https://www.electronjs.org/docs/latest/api/safe-storage)）；没有可用密码库或 Linux 采用 `basic_text` 时，使用 AES-256-GCM 和独立的本地随机密钥，文件权限为 0600。本地密钥方案不能抵御可读取同一用户密钥文件的程序。私钥口令不落盘。临时缓存包含原始日志，目录/文件采用本用户权限；应用异常崩溃可能遗留系统临时目录中的 `ssh-log-viewer-*` 文件夹，可手动删除。

## 仓库

这是工具汇总仓下的独立 Git 仓库，远程仓库为 [huerli/ssh-log-viewer](https://github.com/huerli/ssh-log-viewer)，发行版通过 GitHub Releases 分发。源码不混入已有工具。

已下载的文件和解压结果会记录本地路径，重启后仍可本地搜索。在远程列表点击“查看”或双击已下载的文件时，直接打开同一 SSH 连接对应的本地副本；当前文件搜索也使用该本地文件。匹配搜索优先使用同一 SSH 连接、同一远程目录下已下载的本地副本；存在匹配本地副本时不访问远程目录，并将后续本地搜索范围更新为实际匹配的文件组。普通下载完成也会切换到本地文件组，`.gz` 从本地解码搜索；结果跳转打开本地文件。本地副本不存在时才读取远程。

日志工具栏中的“字体设置”支持选择或输入本机字体名称、设置 10–32 px 字号、预览和恢复默认。点击“应用并保存”后日志正文、行号和搜索结果立即生效，设置在重启后保留；大字号会同步增大行高。未安装的字体使用备用字体。

点击顶部“打开本地文件/文件夹”，在统一选择窗口中选择文件或文件夹（也可输入完整路径）：文件直接打开并以当前文件为搜索范围，文件夹以目录形式浏览并以目录为搜索范围；未选中项目时点击“打开”会打开当前文件夹。左侧切换到本地文件列表；双击子目录进入，使用“上级目录”返回所选文件夹，双击日志或选中后点击“查看”。支持普通日志和 `.gz`，支持 `signal.2026-10-15.*.gz` 等文件名通配匹配，选中本地压缩文件后可点击“解压”；未选中单个文件时，可点击“解压匹配文件”或底部“解压匹配”，批量解压当前列表中匹配的压缩文件（支持 `.gz`、`.zip`、`.tar`、`.tar.gz`、`.tgz`，不递归子目录）。批量任务显示成功/失败数量，单个文件失败不影响其他文件，完成后自动打开解压日志。文件名匹配和“本地文件夹”搜索范围覆盖当前目录的匹配文件，不递归搜索子目录；点击搜索结果直接打开本地文件。可通过“文件来源”切换回远程列表，无需断开 SSH。

应用图标位于 `assets/`，源码启动会在 Linux 用户应用目录注册 `com.teee.sshlogviewer.desktop`，窗口标识与启动入口一致；PNG、ICO、ICNS 同时用于运行和打包。修改后需关闭旧窗口并重新启动才能更新任务栏图标。

SSH 指纹发生变化时（包括目标机器和跳板机），会显示新旧 SHA256 指纹。核对后点击“清除旧指纹并连接”，自动替换该连接的旧记录并继续连接，无需手动清理；取消或取消连接后到达的确认不会替换记录。记录保存在工具自己的配置中，不修改系统 `~/.ssh/known_hosts`；再次连接或重启后仍使用已确认的新指纹。

新下载的文件按“IP/远端文件夹名称/下载时间/原文件名”保存，例如远端 `192.168.1.10` 的 `/data/trace/signal.log` 下载为 `192.168.1.10/trace/2026-10-17_09/signal.log`；时间使用下载时的本地日期和小时，单个下载和批量下载规则一致。远端根目录使用 `root` 文件夹。同名文件保留旧文件，并在扩展名前加入随机后缀。远程解压按“IP/远端文件夹名称/解压时间（YYYY-MM-DD_HH）/压缩包名”保存，重复解压添加 ` (2)`、` (3)` 等编号，归档内原文件名保持不变。下载任务和日志标题显示“来源”，记录在重启后保留；已有下载文件若仍有来源记录，也会显示来源标签。

全文搜索框为空时，点击输入框显示最近 30 条有效搜索记录，按最近使用排序并去重；点击记录或使用方向键与 Enter 回填，回填后点击“搜索全文”执行。搜索发起时即写入本机应用配置，取消搜索或部分文件报错也保留历史；旧版浏览器中的历史会自动迁移，重启后保留，可点击“清空搜索历史”删除。

全文搜索采用增量展示：当前文件、本地文件组和远程匹配文件在搜索过程中持续追加匹配结果，无需等待所有文件搜索完毕；新增结果保留列表滚动位置，取消搜索后保留已显示的结果，发起新搜索时清空上一轮结果。

本地压缩文件按来源文件夹名称归组，例如 `/home/huerli/Desktop/log/server log/signal.log.gz` 解压为“设置的解压目录/server log/signal.log”；同目录的多个压缩包共用 `server log/`，不再按压缩包逐个创建文件夹。归档内部目录保留，同名文件添加 `(2)` 等序号，保留已有文件。日志标题显示实际文件名及来源压缩文件，悬停可查看完整路径；来源信息重启后保留。

搜索结果每条日志右侧提供“复制”，右键菜单及 Ctrl+C 也支持复制：选中该条日志中的文本时复制选中部分，未选中时复制该条日志内容，不带文件名和行号。选择文字或点击复制不会触发结果跳转。

普通全文搜索支持 `*` 通配符，匹配同一条日志中任意长度的内容，例如 `remove readIdle time over 27s * 2098267890303354`；多个片段按出现顺序匹配，不跨行，支持大小写选项。无需勾选“正则”；勾选后仍按标准正则语法搜索（例如 `27s.*2098267890303354`）。

跨文件搜索优先处理搜索范围内当前打开的文件，先展示其匹配结果，再按原顺序搜索其余文件。文件名匹配与搜索范围保持有效，范围外的文件不会自动加入。

点击全局搜索结果跳转后，匹配关键词会在打开日志中自动高亮；`*` 通配搜索会分别高亮前后关键词片段。

搜索结果区的“导出结果”可将当前已显示的匹配结果保存为 TXT、CSV 或 JSON，包含行号和完整原始单行，不限制单行长度，不附加来源文件名或路径。支持搜索进行中或取消后导出当时的结果快照；最多导出展示列表中的 10000 条。TXT/JSON 中标注搜索未完成和展示上限；CSV 使用 UTF-8 BOM，便于表格软件读取。
